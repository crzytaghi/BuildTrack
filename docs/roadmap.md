# Product Roadmap

_Last updated: 2026-11-18_

## MVP — Done
- Auth: signup (with company info and password validation), login, logout, password change
- Company setup on first login (stored server-side)
- Project CRUD with detail views (overview, tasks, expenses, budget, documents)
- Tasks with overdue indicators
- Expenses with categories, vendors, and receipt attachments
- Budget line items and vendor quotes
- Invoices (web)
- Documents with editable notes
- Reports (web): spend by project / vendor / category over date ranges
- Dashboard charts: monthly spend, spend by category
- CI: typecheck plus web, API, and mobile tests on every PR

## Next
- Multi-user per company with role-based access (see `backlog.md`)
- Mobile catch-up to web (reports, invoices, project settings)
- Test coverage for untested API routes and web views

## Later
- Subcontractor portal (bids, schedule updates)
- Expense approvals + notifications
- Accounting integrations
- Multi-company support
